# 折间 ORI

三维折纸工作室：选纸、配色、沿折痕折叠，并把折法导出为可分享的教学视频。

## 本地启动

```sh
npm install
npm run dev
```

## 检查与构建

```sh
npm run typecheck
npm run test
npm run build
```

## 导出教学视频

顶栏「导出视频」打开导出对话框：

- **拍摄方案**：开场定格 → 正背面展示 → 逐步折叠（过渡 + 停留）→ 成品 360° 环绕 → 结束定格，按确认顺序逐帧录制；镜头可开关、时长与每步停留可调。
- **清晰度 / 帧率**：480p / 720p / 1080p，24 / 30 / 60 fps，导出前自由选择。
- **确定性渲染**：帧数只由方案 × 帧率决定，与设备实时播放是否卡顿无关；首帧为平展形态、末帧为成品形态，步骤边界不丢帧、不重复。
- **快照隔离**：点击「开始导出」即冻结当时确认的作品，导出期间可继续修改颜色、步骤与视角，互不影响。
- **任务隔离**：每个任务独立的快照、编码器与文件名（`ORI-教学-{纸张}-{时间戳}-T{序号}-{清晰度}{帧率}`）；连续启动、取消重试、切换纸张互不串用。
- **内存有界**：WebCodecs 逐帧编码（H.264/MP4 优先，VP9/WebM 兜底），原始帧即编即弃，封装数据流式收集，进度对应真实已编码帧数；失败可重试或调整参数，作品不受影响。

端到端验证（需先启动 dev 服务，本机装有 Chromium）：

```sh
node e2e/export.e2e.mjs
```
